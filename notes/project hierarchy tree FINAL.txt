2) main.py
==================================================

main.py
│
├── FastAPI app
│
├── PYDANTIC MODELS
│   ├── CarCreate
│   ├── CustomerLogin
│   ├── CustomerMileageUpdate
│   ├── CarResponse
│   ├── MaintenanceRecordCreate
│   │   ├── car_id
│   │   ├── sv_type
│   │   ├── sv_date
│   │   ├── next_service_date
│   │   ├── sv_mileage
│   │   ├── sv_interval
│   │   ├── cost
│   │   ├── paid_amount
│   │   └── notes
│   └── MaintenanceRecordResponse
│       ├── next_service_date optional
│       └── paid_amount default = 0.0
│
├── CUSTOMER API
│   ├── POST /customer/login
│   └── PUT /customer/mileage
│       └── prevents mileage decreasing
│
├── CAR API
│   ├── POST /cars/
│   ├── GET /cars/
│   ├── GET /cars/{car_id}
│   ├── PUT /cars/{car_id}
│   └── DELETE /cars/{car_id}
│
└── MAINTENANCE RECORD API
    ├── POST /maintenance_records/
    │   ├── verify car
    │   ├── prevent paid_amount > cost
    │   ├── create record
    │   └── update car mileage when needed
    ├── GET /cars/{car_id}/maintenance_records
    │   └── old records without paid_amount fall back to 0.0
    ├── GET /maintenance_records/{record_id}
    ├── PUT /maintenance_records/{record_id}
    │   └── prevent paid_amount > cost
    └── DELETE /maintenance_records/{record_id}

==================================================
SIMPLE PRESENTATION EXPLANATION
==================================================

database.py
└── Handles MongoDB database operations.

main.py
└── FastAPI backend.
    It validates requests and connects Streamlit to MongoDB.

streamlit_app.py
└── Main user interface for Staff and Customer.

chat_agent.py
└── Staff AI assistant with database tools.

customer_chat_agent.py
└── Customer AI assistant restricted to the logged-in customer's data.

tools.py
└── Database tools used by the Staff AI.

llm.py
└── Gemini model configuration.

Overall architecture:

Streamlit Frontend
        ↓
FastAPI Backend
        ↓
DatabaseManager
        ↓
MongoDB Atlas
